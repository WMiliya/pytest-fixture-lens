# Support

## Questions

Use GitHub Discussions if enabled, or open an issue with the `question` label.

## Bugs

Open a bug report with:

- FixtureLens version,
- pytest version,
- Python version,
- a minimal reproduction,
- and a redacted report excerpt if useful.

## Feature ideas

Open a feature request describing the problem first, then the proposed solution.

## Security

See [SECURITY.md](SECURITY.md). Do not open public issues for vulnerabilities.
